# Signals Page Redesign Documentation

**Date:** January 4, 2026  
**Status:** ✅ Completed  
**Purpose:** Transform signals page from manual generation UI to live signal feed for manual demo trading

---

## Overview

The Signals page has been completely redesigned to display real-time trading signals automatically generated by Janus Brain. This allows users to manually execute trades on demo accounts to test the system before enabling automated trading in production.

---

## Key Changes

### Before: Manual Signal Generation
- **UI Focus**: Button to manually trigger signal generation
- **User Flow**: Click button → Wait for task queue → Check results separately
- **Use Case**: Testing signal generation endpoint
- **Problem**: Not useful for actual trading workflow

### After: Live Signal Feed
- **UI Focus**: Real-time display of automatically generated signals
- **User Flow**: View signals → Copy trade details → Execute on demo account
- **Use Case**: Manual demo trading to validate system
- **Benefit**: Practical workflow for system testing

## New Features

### 1. Category Filtering
```
[ALL] [SWING] [SCALP] [DAY] [🔄 Refresh]
```

- **All Categories**: Show signals from all timeframes
- **Swing**: Multi-day position trades (high conviction)
- **Scalp**: Minutes to hours (quick profits)
- **Day**: Intraday positions (close before market close)
- **Refresh**: Manually reload signals

**Implementation:**
- Filter buttons with active state styling
- Selected category highlighted with green accent
- URL parameter support for category filtering

### 2. Signal Cards

Each signal displays:

#### Header Section
- **Symbol** (large, white): Trading pair (e.g., BTC/USDT)
- **Direction Badge**: 
  - 🟢 LONG (green background)
  - 🔴 SHORT (red background)

#### Price Levels
Grid layout (2 columns):
- **Entry Price**: Suggested entry point
- **Stop Loss**: Risk management level (red text)

#### Take Profit Targets
- Multiple TP levels displayed as pills/badges
- Green accent color for positive targets
- Flexible layout (wraps if many targets)

#### Metadata Footer
- **Category**: 📊 SWING/SCALP/DAY
- **Confidence**: 💪 85% (model confidence score)
- **Timestamp**: 🕒 When signal was generated

### 3. Empty State

When no signals are available:
```
🎯
No Signals Yet
Signals will appear here automatically when generated by Janus Brain
```

### 4. Info Banner

Bottom banner with blue accent:
```
💡 Signals are automatically generated by Janus Brain. 
Use these for manual demo trading to test the system. 
Auto-trading will be enabled in production mode.
```

## API Integration

### Endpoint
```
GET /api/v1/signals/history?category={category}
```

### Parameters
- `category` (optional): Filter by signal category
  - Values: `swing`, `scalp`, `day`
  - Omit for all categories

### Response Structure
```json
{
  "signals": [
    {
      "symbol": "BTC/USDT",
      "direction": "LONG",
      "entry_price": 45000.00,
      "stop_loss": 44000.00,
      "take_profit_levels": [46000.00, 47000.00, 48000.00],
      "category": "swing",
      "confidence": 85,
      "timestamp": "2026-01-04T14:30:00Z"
    }
  ]
}
```

### Error Handling
- Network errors: Display error banner with retry option
- Empty response: Show "No Signals Yet" empty state
- Invalid category: Fall back to "all"

## User Workflow

### Manual Demo Trading Process

1. **Monitor Signals Page**
   - Visit `/signals` page
   - Select desired category (or view all)
   - Wait for new signals to appear

2. **Evaluate Signal**
   - Review symbol and direction
   - Check confidence level
   - Validate price levels make sense
   - Consider category timeframe

3. **Execute Trade on Demo Account**
   - Open demo trading platform (e.g., TradingView, MT4)
   - Enter position at suggested entry price
   - Set stop loss at suggested level
   - Set take profit orders at suggested levels

4. **Track Results**
   - Monitor position in trading platform
   - Record outcome for system validation
   - Report issues or feedback

5. **Iterate**
   - Continue testing with more signals
   - Build confidence in system accuracy
   - Validate before enabling auto-trading

## Technical Implementation

### Component Structure
```kotlin
SignalContent()
├── Category Filter Buttons
│   ├── All, Swing, Scalp, Day
│   └── Refresh Button
├── Loading State (animated icon + text)
├── Error State (error banner)
├── Empty State (no signals message)
└── Signal Cards Grid
    └── SignalCard × N
        ├── Direction Accent Bar
        ├── Header (Symbol + Direction Badge)
        ├── Price Levels Grid
        ├── Take Profit Pills
        └── Metadata Footer
```

### State Management
```kotlin
var signals: List<Any>? = null
var isLoading: Boolean = true
var error: String? = null
var selectedCategory: String = "all"
```

### Data Flow
1. User selects category → Update `selectedCategory`
2. `LaunchedEffect(selectedCategory)` triggers
3. `loadSignals()` function fetches from API
4. Update `signals` state
5. UI re-renders with new data

### Responsive Design
- **Grid Layout**: `auto-fit, minmax(320px, 1fr)`
- **Wraps on small screens**: Single column on mobile
- **Touch-friendly**: Buttons have adequate padding
- **Readable**: Font sizes scale appropriately
