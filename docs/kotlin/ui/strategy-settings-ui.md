## Overview

The Strategy Settings UI provides a comprehensive interface for managing trading strategy configurations. Users can create, edit, activate, and manage multiple strategy presets through an intuitive Jetpack Compose interface.

## Quick Start

1. Navigate to Settings from main app menu
2. Choose "Add Preset" for quick start (Conservative/Balanced/Aggressive)
3. Or create custom configuration with "Create Custom"
4. Set one configuration as default
5. Toggle active/inactive as needed

## Key Features

✅ **Preset Templates** - Quick-start configurations  
✅ **Custom Configs** - Full parameter control  
✅ **Real-time Updates** - Reactive UI with StateFlow  
✅ **Persistent Storage** - SQLDelight database  
✅ **Default Selection** - Auto-used for new signals
